# برنامج التقييمات السنوية للموظفين

نسخة مستقلة من وحدة التقييم السنوي في منظومة الوحدة الإدارية.

## التشغيل

```bash
npm install
npm run dev
```

## استيراد ملف الموظفين

يجب أن يحتوي ملف Excel على صفين للعناوين:

1. الصف الأول: أسماء عربية للعرض فقط.
2. الصف الثاني: مفاتيح قاعدة البيانات الإنجليزية، وأهمها `EmpID` و`EmpName` و`EmpJobTitle` و`EmpDept` و`EmpSection`.
3. الصف الثالث وما بعده: بيانات الموظفين.

يتم حفظ البيانات محليًا في المتصفح، ولا يتم إرسالها إلى أي خدمة خارجية.
